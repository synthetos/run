# Theme, tokens, icons (ROADMAP P0-05)

run.synthetos.com uses the synthetos.com "blueprint" (Datasheet) theme
(RUN_PLAN §7.1). The site is never imported; its tokens are copied.

## Files

| File | What |
|---|---|
| `apps/web/src/styles/tokens.css` | Theme tokens (copied), safety tokens, safety bar tokens, drafting accent tokens; light and dark |
| `apps/web/src/styles/tokens.pin.json` | The synthetos.com commit the theme tokens were copied from |
| `apps/web/src/styles/base.css`, `components.css` | Drafting-grid page, sheets with title blocks, labels, buttons, inputs, tables, safety bar, stop button |
| `docs/design/contrast.md` | Generated contrast table (`pnpm gen:contrast`) |
| `apps/web/public/manifest.webmanifest`, `apps/web/public/icons/` | Installable app (D38); icons generated by `pnpm gen:icons` |
| `docs/design/screenshots/p0-05/` | Shell and safety page, light and dark, 320 and 1280 px (`RUN_SCREENSHOTS=1 pnpm e2e`) |

## Token drift

```
pnpm tokens:drift --site ../synthetos/synthetos.com              # copy vs pinned ref
pnpm tokens:drift --site ../synthetos/synthetos.com --upstream origin/main   # has the site moved?
RUN_SITE_REPO=../synthetos/synthetos.com pnpm --filter @synthetos/gates test  # same check inside the test suite
```

The check reads the clone with `git show` and never fetches. To take a site
theme change: copy the new values into the theme section of `tokens.css` (both
dark blocks), move `ref` in `tokens.pin.json`, then run the drift check,
`pnpm gen:contrast` and the tests. The unit tests always run the comparator on
fixtures; the comparison against the real site needs a clone (CI has none
yet, see the P0-05 lead actions).

## Safety colours

`--danger --warn --live --state-run --state-hold --state-alarm` are run's own
and are checked at 4.5:1 against `--sheet`, `--paper` and `--blue-wash` in
both themes. The safety bar (signal orange, black hazard stripes, white state
band) and the stop button (black, red pause mark) use tokens that are the same
in both themes; an E2E test asserts no element outside the bar uses those
colours.

## Drafting accent (tan)

`--tan --tan-wash --on-tan` are run's own warm accent, a kraft or blueprint
vellum tan beside the pencil blue. synthetos.com has no such token yet; the
names are chosen so the site can adopt them as they are (then they move into
the copied theme section and the pin). Values: light `#836428` / `#f5eedf` /
`#ffffff`, dark `#d6b97f` / `#2b2416` / `#1a140a`, checked in the contrast
table (tan at 4.5:1 as text on `--sheet`, `--paper` and `--tan-wash`).

Use them sparingly: section labels and rules, secondary selection accents, the
setup bed, material swatches, the board drawing's terminal highlights. Blue
stays primary and the safety colours stay reserved.
